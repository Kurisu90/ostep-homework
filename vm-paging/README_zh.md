
# 概觀

在這份作業中，你會使用一個簡單的程式（也就是 `paging-linear-translate_zh.py`，
它是 `paging-linear-translate.py` 的中文版本）來檢驗自己是否理解「線性頁表」
（linear page table）如何進行虛擬位址到實體位址的轉譯。要執行這個程式，
記得輸入程式的名稱（`./paging-linear-translate_zh.py`），或者也可以用
（`python paging-linear-translate_zh.py`）。加上 `-h`（help）旗標執行時，
你會看到：

```sh
prompt> ./paging-linear-translate_zh.py -h
Usage: paging-linear-translate_zh.py [options]

Options:
  -h, --help            show this help message and exit
  -A ADDRESSES, --addresses=ADDRESSES
                        一組以逗號分隔的頁面，用來存取；-1 代表隨機產生
  -s SEED, --seed=SEED  隨機種子
  -a ASIZE, --asize=ASIZE
                        位址空間大小（例如 16、64k、32m、1g）
  -p PSIZE, --physmem=PSIZE
                        實體記憶體大小（例如 16、64k、32m、1g）
  -P PAGESIZE, --pagesize=PAGESIZE
                        頁面大小（例如 4k、8k 等）
  -n NUM, --numaddrs=NUM
                        要產生的虛擬位址數量
  -u USED, --used=USED  虛擬位址空間中已使用的百分比
  -v                    詳細模式
  -c                    幫我計算答案
```

（`-h, --help` 這一行本身是 Python `optparse` 套件內建的說明文字，並非由
這個腳本產生，因此仍會顯示英文原文；其餘所有選項的說明都已翻譯成中文。）

首先，不加任何參數執行這個程式：

```sh
prompt> ./paging-linear-translate_zh.py
參數 隨機種子 0
參數 位址空間大小 16k
參數 實體記憶體大小 64k
參數 頁面大小 4k
參數 詳細模式 False
參數 位址清單 -1


頁表的格式很簡單：
最高位（最左邊）的那個位元是「有效位元（VALID bit）」。
  若該位元為 1，代表這個項目其餘的部分就是 PFN。
  若該位元為 0，代表這個頁面是無效的。
如果你想在頁表的每個項目旁邊都印出它的 VPN 編號，
可以使用詳細模式（-v）。

頁表（從第 0 個項目一路列到最大大小）
  0x8000000c
  0x00000000
  0x00000000
  0x80000006

虛擬位址軌跡
  VA 0x00003229 (十進位:    12841) --> PA 或無效位址？
  VA 0x00001369 (十進位:     4969) --> PA 或無效位址？
  VA 0x00001e80 (十進位:     7808) --> PA 或無效位址？
  VA 0x00002556 (十進位:     9558) --> PA 或無效位址？
  VA 0x00003a1e (十進位:    14878) --> PA 或無效位址？
```

對於每一個虛擬位址，請寫下它轉譯後對應的實體位址，或者寫下它是一個超出
範圍的位址（例如發生了分段錯誤，segmentation fault）。

如你所見，這個程式為你準備了某個行程（process）的頁表（記得，在真實系統
中，使用線性頁表的話，每個行程都有自己的一份頁表；這裡我們只專注在一個
行程、它的位址空間，因此也就只有一份頁表）。這份頁表會告訴你，位址空間
中的每一個虛擬頁號（VPN）究竟對應到哪一個實體頁框號（PFN），因而是有效
的，或者根本無效。

頁表項目（page-table entry）的格式很簡單：最左邊（最高位）的那個位元是
有效位元；剩下的位元，如果有效位元是 1，就是 PFN。

在上面的例子中，這份頁表把 VPN 0 對應到 PFN 0xc（十進位 12），把 VPN 3
對應到 PFN 0x6（十進位 6），另外兩個虛擬頁面（1 和 2）則標示為無效。

因為頁表其實就是一個線性陣列，所以上面印出的內容，其實就是如果你直接
去看記憶體裡的位元組時會看到的樣子。不過，如果你搭配詳細模式（`-v`）
旗標執行，有時候用起來會更輕鬆；這個旗標還會額外印出頁表中每個項目的
VPN（也就是索引值）。用 `-v` 旗標重新執行上面的例子：

```sh
prompt> ./paging-linear-translate_zh.py -v
參數 隨機種子 0
參數 位址空間大小 16k
參數 實體記憶體大小 64k
參數 頁面大小 4k
參數 詳細模式 True
參數 位址清單 -1


頁表的格式很簡單：
最高位（最左邊）的那個位元是「有效位元（VALID bit）」。
  若該位元為 1，代表這個項目其餘的部分就是 PFN。
  若該位元為 0，代表這個頁面是無效的。
如果你想在頁表的每個項目旁邊都印出它的 VPN 編號，
可以使用詳細模式（-v）。

頁表（從第 0 個項目一路列到最大大小）
  [       0]  0x8000000c
  [       1]  0x00000000
  [       2]  0x00000000
  [       3]  0x80000006

虛擬位址軌跡
  VA 0x00003229 (十進位:    12841) --> PA 或無效位址？
  VA 0x00001369 (十進位:     4969) --> PA 或無效位址？
  VA 0x00001e80 (十進位:     7808) --> PA 或無效位址？
  VA 0x00002556 (十進位:     9558) --> PA 或無效位址？
  VA 0x00003a1e (十進位:    14878) --> PA 或無效位址？
```

你的任務，就是利用這份頁表，把上面軌跡中給你的虛擬位址轉譯成實體位址。
我們先看第一個：VA 0x3229。要把這個虛擬位址轉譯成實體位址，首先得把它
拆解成組成它的兩個部分：虛擬頁號與偏移量（offset）。我們可以透過位址
空間大小與頁面大小算出來。在這個例子中，位址空間大小設為 16 KB（是個
非常小的位址空間），頁面大小是 4 KB。因此，我們知道虛擬位址一共有 14
個位元，其中偏移量佔 12 個位元，剩下 2 個位元留給 VPN。所以，我們的
位址 0x3229，換成二進位是 `11 0010 0010 1001`，可以看出最前面兩個位元
指定了 VPN。因此，0x3229 落在虛擬頁面 3，偏移量是 0x229。

接著我們查頁表，看看 VPN 3 是有效並對應到某個實體頁框，還是無效的，
結果發現它確實有效（最高位元是 1），而且對應到實體頁面 6。於是我們就
可以把實體頁面 6 加上偏移量，組合出最終的實體位址：0x6000（把實體頁面
編號移到正確的位置）再「或」上 0x0229（偏移量），得到最終的實體位址：
0x6229。因此，我們可以看到，這個例子中虛擬位址 0x3229 轉譯後的實體位址
是 0x6229。

要看到其餘的解答（當然是在你自己算過一遍之後！），只要照慣例加上 `-c`
旗標執行即可：

```sh
prompt> ./paging-linear-translate_zh.py -c
參數 隨機種子 0
參數 位址空間大小 16k
參數 實體記憶體大小 64k
參數 頁面大小 4k
參數 詳細模式 False
參數 位址清單 -1


頁表的格式很簡單：
最高位（最左邊）的那個位元是「有效位元（VALID bit）」。
  若該位元為 1，代表這個項目其餘的部分就是 PFN。
  若該位元為 0，代表這個頁面是無效的。
如果你想在頁表的每個項目旁邊都印出它的 VPN 編號，
可以使用詳細模式（-v）。

頁表（從第 0 個項目一路列到最大大小）
  0x8000000c
  0x00000000
  0x00000000
  0x80000006

虛擬位址軌跡
  VA 0x00003229 (十進位:    12841) --> 00006229 (十進位    25129) [VPN 3]
  VA 0x00001369 (十進位:     4969) -->  無效（VPN 1 並非有效）
  VA 0x00001e80 (十進位:     7808) -->  無效（VPN 1 並非有效）
  VA 0x00002556 (十進位:     9558) -->  無效（VPN 2 並非有效）
  VA 0x00003a1e (十進位:    14878) --> 00006a1e (十進位    27166) [VPN 3]
```

當然，你也可以調整很多參數，設計出更有趣的題目。加上 `-h` 旗標執行程式，
即可看到有哪些選項：

* `-s` 旗標會改變隨機種子，因此也會產生不同的頁表內容，以及不同的待轉譯
  虛擬位址。
* `-a` 旗標會改變位址空間的大小。
* `-p` 旗標會改變實體記憶體的大小。
* `-P` 旗標會改變頁面的大小。
* `-n` 旗標可以用來產生更多待轉譯的位址（預設是 5 個）。
* `-u` 旗標會改變有效對應所佔的比例，範圍從 0%（`-u 0`）到 100%
  （`-u 100`）。預設值是 50，也就是說虛擬位址空間裡大約有一半的頁面
  會是有效的。
* `-v` 旗標會額外印出 VPN 編號，讓你查表時更方便。
