
# 概述

在這份作業中,你將使用一個名為 `mem.c` 的簡單程式來研究 swap(置換)的效能。
這個程式非常簡單:它配置一個特定大小的整數陣列,然後不斷地(重複地)
走訪整個陣列,把每個值加一。

輸入 `make` 來建置它(關於建置的細節,請參考 `Makefile`)。

以下是這個程式對應的繁體中文版本 `mem_zh.c`。輸入 `make -f Makefile_zh`
即可建置中文版,產生的執行檔名稱為 `mem_zh`,不會覆蓋原本的 `mem`。

接著,輸入 `./mem_zh` 並加上一個數字來執行它。這個數字代表陣列的大小
(單位為 MB)。因此,若要以小陣列(大小 1 MB)執行:

```sh
prompt> ./mem_zh 1
```

若要以較大的陣列(大小 1 GB)執行:

```sh
prompt> ./mem_zh 1024
```

這個程式會印出每次走訪迴圈所花的時間,以及頻寬(單位為 MB/s)。頻寬特別
值得關注,因為它讓你了解目前使用的系統在資料搬移上能有多快;在現代系統
上,這通常會落在 GB/s 的等級。

以下是一次典型執行的輸出範例:

```sh
prompt> ./mem_zh 500
配置 524288000 個位元組 (500.00 MB)
  陣列中的整數個數: 131072000
第 0 輪耗時 123.92 毫秒 (頻寬: 4034.89 MB/s)
第 4 輪耗時 65.40 毫秒 (頻寬: 7645.83 MB/s)
第 7 輪耗時 68.38 毫秒 (頻寬: 7312.30 MB/s)
第 10 輪耗時 73.08 毫秒 (頻寬: 6842.01 MB/s)
^C
prompt> 
```

程式一開始會告訴你配置了多少記憶體(以位元組、MB,以及陣列中整數個數
三種方式呈現),接著開始走訪整個陣列。上面範例中的第一輪(第 0 輪)花
了大約 124 毫秒;由於程式在略多於十分之一秒的時間內存取了 500 MB 的
資料,算出來的頻寬便是大約 4000 MB/s 出頭。

程式接著會不斷重複同樣的動作,依序印出第 4 輪、第 7 輪等等的結果。

重要:要停止這個程式,你必須手動將它中止。在 Linux(以及所有 Unix 系
統)上,這可以透過輸入 control-C(^C)來完成,如上面範例所示。

請注意,當你使用較小的陣列大小執行時,並不是每一輪的效能數據都會被
印出來。例如:

```sh
prompt> ./mem_zh 1
配置 1048576 個位元組 (1.00 MB)
  陣列中的整數個數: 262144
第 0 輪耗時 0.77 毫秒 (頻寬: 1303.79 MB/s)
第 3040 輪耗時 0.07 毫秒 (頻寬: 14926.35 MB/s)
第 5854 輪耗時 0.07 毫秒 (頻寬: 14266.34 MB/s)
第 8623 輪耗時 0.07 毫秒 (頻寬: 14315.03 MB/s)
^C
prompt> 
```

在這種情況下,程式只會印出部分取樣的結果,以免螢幕被過多的輸出訊息
淹沒。

程式本身的邏輯很容易理解。第一個重要的部分是記憶體配置:

```c
    // the big memory allocation happens here
    int *x = malloc(size_in_bytes);
```

接著,主要迴圈開始:

```c
    while (1) {
	x[i++] += 1; // main work of loop done here.
```

其餘的部分只是計時與印出資訊而已。詳細內容請參考 `mem_zh.c`(邏輯與
原始的 `mem.c` 完全相同,只是把註解與畫面上顯示的文字換成了繁體中文)。

這份作業的重點,主要圍繞在使用 vmstat 這個工具來監控系統當下的狀態。
請閱讀 vmstat 的 man page(輸入 `man vmstat`)以了解它的運作方式,以
及每一欄輸出代表的意義。
