
# 概觀

`scheduler_zh.py` 是 `scheduler.py` 的中文版本，功能完全相同，只是
把所有的說明文字、命令列選項說明，以及執行時印出的訊息都換成了中
文，方便你觀察不同排程器在反應時間、週轉時間、總等待時間等排程指
標下的表現。這裡「實作」了三種排程器：FIFO、SJF、RR。

執行這個程式分成兩個步驟。

第一步，先不要加上 `-c` 旗標執行：這樣只會顯示題目，不會告訴你答
案。舉例來說，如果你想用 FIFO 策略，計算三個工作的反應時間、週轉時
間與等待時間，可以這樣執行：

```sh
prompt> ./scheduler_zh.py -p FIFO -j 3 -s 100
```

如果這樣不能執行，試試看：
```sh
prompt> python ./scheduler_zh.py -p FIFO -j 3 -s 100
```

這樣會指定 FIFO 策略、三個工作，並且很重要的一點是，用了固定的隨機
種子 100。如果你想看這個確切題目的解答，之後也必須指定完全相同的隨
機種子。我們實際執行看看會發生什麼事，你應該會看到這樣的內容：

```sh
prompt> ./scheduler_zh.py -p FIFO -j 3 -s 100
參數 policy FIFO
參數 jobs 3
參數 maxlen 10
參數 seed 100

以下是工作清單，附上每個工作的執行時間：
  工作 0 （長度 = 2 ）
  工作 1 （長度 = 5 ）
  工作 2 （長度 = 8 ）
```

請計算出每個工作的週轉時間、反應時間，以及等待時間。算完之後，用
相同的參數再執行一次這個程式，並加上 `-c`，就能得到正確答案。你可
以用 `-s <某個數字>` 或自訂工作清單（例如 `-l 10,15,20`），來幫自
己產生不同的練習題目。

從這個例子可以看到，程式產生了三個工作：工作 0 長度為 2，工作 1 長
度為 5，工作 2 長度為 8。就像程式提示的一樣，你現在可以用這些資訊
自己動手算一些統計數據，看看自己是不是真的搞懂了這些基本概念。

算完之後，你可以用同一個程式來「解」這道題目，看看自己算得對不
對。作法是加上 `-c` 旗標，輸出如下：

```sh
prompt> ./scheduler_zh.py -p FIFO -j 3 -s 100 -c
參數 policy FIFO
參數 jobs 3
參數 maxlen 10
參數 seed 100

以下是工作清單，附上每個工作的執行時間：
  工作 0 （長度 = 2 ）
  工作 1 （長度 = 5 ）
  工作 2 （長度 = 8 ）


** 解答 **

執行記錄：
  [ 時間   0 ] 執行工作 0，共 2.00 秒（於 2.00 完成）
  [ 時間   2 ] 執行工作 1，共 5.00 秒（於 7.00 完成）
  [ 時間   7 ] 執行工作 2，共 8.00 秒（於 15.00 完成）

最終統計：
  工作   0 -- 反應時間：0.00  週轉時間 2.00  等待時間 0.00
  工作   1 -- 反應時間：2.00  週轉時間 7.00  等待時間 2.00
  工作   2 -- 反應時間：7.00  週轉時間 15.00  等待時間 7.00

  平均 -- 反應時間：3.00  週轉時間 8.00  等待時間 3.00
```

如圖所示，加上 `-c` 旗標之後，程式就會顯示實際發生的過程。工作 0 先
執行了 2 秒，接著工作 1 執行了 5 秒，最後工作 2 執行了 8 秒。畢竟是
FIFO，一點都不難！執行記錄（execution trace）把這些結果都列出來
了。

最終統計數據也很有用：程式算出了「反應時間」（response time，工作
從抵達到第一次被執行之前，等待了多久）、「週轉時間」（turnaround
time，從工作第一次抵達到完成總共花了多久）、以及總「等待時間」
（wait time，處於就緒但沒有被執行的時間總和）。這些數據會先列出每
個工作各自的數值，再列出所有工作的平均值。當然，你應該要在加上
`-c` 旗標之前，自己先把這些東西都算出來！

如果你想嘗試同一類的題目，但換一組不同的輸入，可以試著改變工作數
量、隨機種子，或兩者都改。不同的隨機種子基本上可以讓你產生無限多
種不同的練習題目，而 `-c` 旗標則可以讓你檢查自己算得對不對。持續這
樣練習，直到你真的覺得自己搞懂這些概念為止。

另一個很有用的旗標是 `-l`（小寫的 L），可以讓你指定確切想要排程的
工作內容。舉例來說，如果你想知道 SJF 在三個長度分別為 5、10、15 的
工作下會如何表現，可以執行：

```sh
prompt> ./scheduler_zh.py -p SJF -l 5,10,15
參數 policy SJF
參數 jlist 5,10,15

以下是工作清單，附上每個工作的執行時間：
  工作 0 （長度 = 5.0 ）
  工作 1 （長度 = 10.0 ）
  工作 2 （長度 = 15.0 ）
...
```

接著一樣可以用 `-c` 來解出答案。要注意的是，當你自己指定確切的工作
內容時，就不需要再指定隨機種子或工作數量了：工作的長度會直接從你
提供的逗號分隔清單中讀取。

當然，換成 SJF（最短工作優先）甚至是 RR（Round Robin，輪詢式）排程
器時，會發生更多有趣的事情。動手試試看吧！

你也隨時可以執行

```sh
prompt> ./scheduler_zh.py -h
```

來取得完整的旗標與選項清單（包括像是設定 RR 排程器時間片長度這類
的選項）。
