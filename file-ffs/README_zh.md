
# 總覽

這是 `ffs_zh.py` 的說明文件，它是 `ffs.py`（一個 FFS 配置策略模擬器）的
中文版本，模擬邏輯完全相同，只是把說明文字、命令列選項說明，以及執行
時印出的訊息都換成了中文。你可以用它來研究 FFS 在不同的檔案與目錄
建立情境下的行為。

這個工具的用法是透過 `-f` 旗標指定一個「指令檔案」，裡面包含一系列
檔案建立、檔案刪除、目錄建立的操作。

舉例來說，執行：

```sh
prompt> ./ffs_zh.py -f in.example1 -c
```

就可以看到課本中「FFS 配置如何運作」那個第一個範例的輸出。

檔案 `in.example1` 裡的內容如下（這是給模擬器讀取的指令檔，格式本身
沒有翻譯，因為 `file`、`dir`、`delete`、`dump` 是模擬器內建解析的
固定關鍵字）：

```sh
dir /a
dir /b
file /a/c 2
file /a/d 2
file /a/e 2
file /b/f 2
```

這告訴模擬器要建立兩個目錄（/a 與 /b）和四個檔案（/a/c、/a/d、/a/e、
/b/f）。根目錄則是預設就會建立好的。

模擬器的輸出，是目前所有存在的檔案與目錄，其 inode 與資料區塊分別
位於哪裡。舉例來說，執行上面的指令後（加上 -c 旗標來看結果），你會
看到：

```sh
prompt> ./ffs_zh.py -f in.example1 -c

群組數量:          10
每組 inode 數:     10
每組區塊數:        30

空閒資料區塊: 289（共 300）
空閒 inode 數: 93（共 100）

是否分散 inode？  False
是否分散資料？    False
連續配置需求:     1

     00000000000000000000 1111111111 2222222222
     01234567890123456789 0123456789 0123456789

群組 inodes    data
    0 /--------- /--------- ---------- ----------
    1 acde------ accddee--- ---------- ----------
    2 bf-------- bff------- ---------- ----------
    3 ---------- ---------- ---------- ----------
    4 ---------- ---------- ---------- ----------
    5 ---------- ---------- ---------- ----------
    6 ---------- ---------- ---------- ----------
    7 ---------- ---------- ---------- ----------
    8 ---------- ---------- ---------- ----------
    9 ---------- ---------- ---------- ----------

prompt>
```

輸出的第一部分，顯示了這次模擬的各種參數，從建立了幾個 FFS 磁柱群組
（cylinder group），到一些配置策略的細節。不過輸出的主要內容，其實是
實際的配置地圖：

```sh
     00000000000000000000 1111111111 2222222222
     01234567890123456789 0123456789 0123456789

群組 inodes    data
    0 /--------- /--------- ---------- ----------
    1 acde------ accddee--- ---------- ----------
    2 bf-------- bff------- ---------- ----------
    3 ---------- ---------- ---------- ----------
    4 ---------- ---------- ---------- ----------
    5 ---------- ---------- ---------- ----------
    6 ---------- ---------- ---------- ----------
    7 ---------- ---------- ---------- ----------
    8 ---------- ---------- ---------- ----------
    9 ---------- ---------- ---------- ----------
```

（表頭那兩行的數字是欄位編號，`inodes` 與 `data` 這兩個欄位標題維持
原文未翻譯，因為程式內部是用這兩個英文字的長度來計算對齊用的空格
數量，翻譯成中文會破壞版面對齊，所以刻意保留原樣。）

以這次的設定來說，我們建立了一個有 10 個群組的檔案系統，每個群組有
10 個 inode 與 30 個資料區塊。每個群組會分別顯示 inode 與資料區塊，
以及它們被配置的情況。如果是空的，就顯示 `-`；否則，每個檔案會用
不同的符號表示。

如果你想看到符號和檔名的對照表，可以加上 `-M` 旗標：

```sh
prompt> ./ffs_zh.py -f in.example1 -c -M
```

這樣輸出的最後面就會多一個表格，說明每個符號代表的意思：

```sh
符號    inode#  檔名         檔案類型 
/            0  /            目錄         
a           10  /a           目錄         
c           11  /a/c         一般檔案       
d           12  /a/d         一般檔案       
e           13  /a/e         一般檔案       
b           20  /b           目錄         
f           21  /b/f         一般檔案
```

（這裡的「檔案類型」欄位顯示的是「目錄」或「一般檔案」，對應原始
英文版程式裡的 `directory` 與 `regular`。）

在這裡，你可以看到根目錄是用符號 `/` 表示，檔案 `/a` 是用符號 `a`
表示，依此類推。

從輸出可以觀察到一些有趣的現象：
- 根目錄的 inode 位於群組 0 的 inode 表格的第一個位置
- 根目錄的資料區塊，是第一個被配置出去的資料區塊（也在群組 0）
- 目錄 /a 被放在群組 1，目錄 /b 被放在群組 2
- 每個一般檔案的 inode 與資料，都和它們的父目錄 inode 位於同一個
  群組中（這正是 FFS 的設計原則）

其餘的選項讓你可以嘗試 FFS 的各種變化玩法，如下：

```sh
prompt> ./ffs_zh.py -h
Usage: ffs_zh.py [options]

Options:
  -h, --help            show this help message and exit
  -s SEED, --seed=SEED  隨機種子
  -n NUM_GROUPS, --num_groups=NUM_GROUPS
                        區塊群組（block group）的數量
  -d BLOCKS_PER_GROUP, --datablocks_per_groups=BLOCKS_PER_GROUP
                        每個群組的資料區塊數量
  -i INODES_PER_GROUP, --inodes_per_group=INODES_PER_GROUP
                        每個群組的 inode 數量
  -L LARGE_FILE_EXCEPTION, --large_file_exception=LARGE_FILE_EXCEPTION
                        0 表示關閉；N>0 表示：檔案在群組中配置多少個區塊後，才會分散到下一個群組
  -f INPUT_FILE, --input_file=INPUT_FILE
                        指令檔案
  -I, --spread_inodes   不把檔案的 inode 放在父目錄所在的群組，而是平均分散到所有群組中
  -D, --spread_data     不把資料放在 inode 附近，而是平均分散到所有群組中
  -A ALLOCATE_FARAWAY, --allocate_faraway=ALLOCATE_FARAWAY
                        選擇群組時，一次檢查這麼多個群組
  -C CONTIG_ALLOCATION_POLICY, --contig_allocation_policy=CONTIG_ALLOCATION_POLICY
                        配置時需要的連續空閒區塊數量
  -T, --show_spans      顯示檔案與目錄的跨距（span）
  -M, --show_symbol_map
                        顯示符號對照表
  -B, --show_block_addresses
                        在群組旁顯示區塊位址
  -S, --do_per_file_stats
                        印出詳細的 inode 統計資訊
  -v, --show_file_ops   印出每個操作詳細的成功/失敗資訊
  -c, --compute         幫我計算答案
```

我們會在作業中進一步探索這些選項。
