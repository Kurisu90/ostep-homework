
# 總覽

`checksum_zh.py` 是 `checksum.py` 的中文版本，程式本身非常簡單：它可以
用來計算幾種不同類型的校驗碼（checksum）──加總式（addition）、
互斥或式（xor）、以及 fletcher 校驗碼──計算的對象可以是程式自己隨機
產生的數值，也可以是你自行指定的一串位元組。

在預設模式下執行：

```sh
prompt> ./checksum_zh.py

選項 seed（隨機種子） 0
選項 data_size（資料位元組數量） 4
選項 data（資料內容） 

十進位：          216        194        107         66 
十六進位：       0xd8       0xc2       0x6b       0x42 
二進位：   0b11011000 0b11000010 0b01101011 0b01000010 

加總：    ?
互斥或：  ?
Fletcher：?

prompt>
```

在這個例子中，程式隨機產生了四個數值（也就是「資料」）：216、194、
107、66（十進位）。這些數值同時也以十六進位與二進位的形式呈現。

接著程式會要求你自己計算出加總式、互斥或式、以及 fletcher 校驗碼。
加總式校驗碼就是把每個位元組加總起來，再對 256 取餘數（結果只有
一個位元組）。互斥或式校驗碼則是把每個位元組做互斥或運算（結果同樣
只有一個位元組）。最後，fletcher 校驗碼是計算課本內文中介紹過的兩個
部分（總共兩個位元組）。

你可以改變種子來取得不同的題目：

```sh
prompt> ./checksum_zh.py -s 1

選項 seed（隨機種子） 1
選項 data_size（資料位元組數量） 4
選項 data（資料內容） 

十進位：           34        216        195         65 
十六進位：       0x22       0xd8       0xc3       0x41 
二進位：   0b00100010 0b11011000 0b11000011 0b01000001 

加總：    ?
互斥或：  ?
Fletcher：?

prompt> 
```

你也可以指定隨機資料要有多長：

```sh
prompt> ./checksum_zh.py -D 2

...

你也可以自行指定資料內容：

prompt> ./checksum_zh.py -D 1,2,3,4

選項 seed（隨機種子） 0
選項 data_size（資料位元組數量） 4
選項 data（資料內容） 1,2,3,4

十進位：            1          2          3          4 
十六進位：       0x01       0x02       0x03       0x04 
二進位：   0b00000001 0b00000010 0b00000011 0b00000100 

加總：    ?
互斥或：  ?
Fletcher：?

prompt> 
```

最後，你可以加上 `-c` 讓程式幫你把校驗碼都算出來：

```sh
prompt> ./checksum_zh.py -D 1,2,3,4 -c

選項 seed（隨機種子） 0
選項 data_size（資料位元組數量） 4
選項 data（資料內容） 1,2,3,4

十進位：            1          2          3          4 
十六進位：       0x01       0x02       0x03       0x04 
二進位：   0b00000001 0b00000010 0b00000011 0b00000100 

加總：           10       (0b00001010)
互斥或：          4       (0b00000100)
Fletcher(a,b)：  10, 20   (0b00001010,0b00010100)

prompt> 
```
