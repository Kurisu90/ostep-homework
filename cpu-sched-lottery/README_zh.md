
# 概觀

`lottery_zh.py` 是 `lottery.py` 的中文版本，功能完全相同，只是把所
有的說明文字、命令列選項說明，以及執行時印出的訊息都換成了中文，
方便你了解「彩票排程器」（lottery scheduler）是怎麼運作的。跟以往一
樣，執行這個程式分成兩個步驟。第一步，先不加 `-c` 旗標執行：這樣只
會顯示題目，不會告訴你答案。

```sh
prompt> ./lottery_zh.py -j 2 -s 0
...
以下是工作清單，附上每個工作的執行時間：
  工作 0 （長度 = 8，票數 = 75）
  工作 1 （長度 = 4，票數 = 25）

以下是你（最多）會需要用到的亂數清單：
亂數 511275
亂數 404934
亂數 783799
亂數 303313
亂數 476597
亂數 583382
亂數 908113
亂數 504687
亂數 281838
亂數 755804
亂數 618369
亂數 250506
```

用這種方式執行模擬器時，程式會先幫你隨機產生一些工作（這裡長度分
別是 8 和 4），每個工作各自擁有一定數量的票（這裡分別是 75 和
25）。模擬器同時也會給你一份亂數清單，你需要用這些亂數來推算彩票排
程器實際上會怎麼做。這些亂數的範圍是 0 到一個很大的數字之間；因
此，你必須使用取餘數（modulo）運算，才能算出中獎的是哪一張票（也就
是說，中獎的票號應該等於這個亂數對系統中總票數取餘數的結果）。

加上 `-c` 執行，就會準確顯示你原本應該要自己算出來的內容：

從這份記錄可以看出，你要做的事情就是：用亂數算出哪一張票中獎，然
後根據中獎的票，找出應該執行哪一個工作。重複這個過程，直到所有工
作都執行完畢為止。就是這麼簡單——你只是親手模擬彩票排程器實際上會
做的事而已！

為了讓這件事更清楚一點，我們來看看上面例子中第一次做的決定。此
時，系統中有兩個工作（工作 0 執行時間為 8、擁有 75 張票；工作 1 執
行時間為 4、擁有 25 張票）。我們拿到的第一個亂數是 511275。因為系
統中總共有 100 張票，511275 % 100 等於 75，所以 75 就是我們的中獎
號碼。

如果 75 號中獎，我們就依序在工作清單裡尋找，直到找到它為止。第一
筆是工作 0，擁有 0 到 74 號的票（共 75 張），並沒有中獎；下一筆是工
作 1，於是我們找到了中獎者，因此接下來就執行工作 1 一個時間片的長
度（在這個例子裡是 1）。整個過程會顯示成這樣：

```sh
亂數 511275 -> 中獎的票是 75（共 100 張）-> 執行工作 1
  工作：
 (  工作:0 剩餘時間:8 票數:75 )  (* 工作:1 剩餘時間:4 票數:25 ) 
```

如你所見，第一行摘要說明發生了什麼事，第二行則單純列出整個工作佇
列，並用 `*` 標出被選中的工作。

這個模擬器還有一些其他選項，大部分應該一看就懂。特別值得一提的
是，`-l`／`--jlist` 旗標可以讓你指定確切的一組工作及其票數，而不是
每次都用隨機產生的工作清單。

```sh
prompt> ./lottery_zh.py -h
Usage: lottery_zh.py [options]

Options:
  -h, --help            show this help message and exit
  -s SEED, --seed=SEED  隨機種子
  -j JOBS, --jobs=JOBS  系統中的工作數量
  -l JLIST, --jlist=JLIST
                        不要隨機產生工作，改用逗號分隔的執行時間與票數清單來指定（例如 10:100,20:100
                        代表有兩個工作，執行時間分別是 10 和 20，各自擁有 100 張票）
  -m MAXLEN, --maxlen=MAXLEN
                        工作的最大長度
  -T MAXTICKET, --maxticket=MAXTICKET
                        隨機分配時，票數的最大值
  -q QUANTUM, --quantum=QUANTUM
                        時間片長度
  -c, --compute         幫我計算答案
```

（`-h, --help` 那一行是 optparse 套件內建、寫死的英文文字，無法從
程式裡改成中文，因此保留原樣；其餘每一項選項的說明都已翻譯成中
文。）
