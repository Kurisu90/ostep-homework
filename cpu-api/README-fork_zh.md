
# 概觀：`fork_zh.py`

`fork_zh.py` 是 `fork.py` 的中文版本，功能完全相同，只是把所有的說明
文字、命令列選項說明，以及執行時印出的訊息都換成了中文，方便閱讀與
理解「行程樹」（process tree）在行程被建立與結束時是怎麼變化的。

要執行它，只要輸入：
```sh
prompt> ./fork_zh.py
```

你會看到一連串的動作，例如某個行程呼叫 `fork` 建立了另一個行程，或
是某個行程呼叫 `exit` 結束執行。

每個正在執行的行程可以有多個子行程（或完全沒有）。除了最初的那個
行程（這裡簡稱為 `a`）之外，每個行程都恰好只有一個父行程。因此，所
有行程之間的關係會形成一棵樹，樹根就是最初的那個行程。我們把這棵
樹稱為「行程樹」（Process Tree），而這份簡單的作業重點，就是要理解
隨著行程不斷地被建立與結束，這棵樹的形狀會如何變化。

# 簡單範例

這是一個簡單的範例：
```sh
prompt> ./fork_zh.py -s 4

                           行程樹（Process Tree）：
                               a

動作： a fork 出 b
行程樹？
動作： a fork 出 c
行程樹？
動作： b fork 出 d
行程樹？
動作： d 結束執行
行程樹？
動作： a fork 出 e
行程樹？
```

從這份輸出中可以看到兩件事。第一，在最前面顯示的是系統的初始狀態；
可以看到，一開始只有一個行程 `a`。作業系統經常會建立一個或少數幾個
初始行程來啟動整個系統；例如在 Unix 上，這個初始行程就叫做 `init`，
系統執行期間會由它衍生出其他行程。

第二，你會看到一連串的「動作」（`動作：`）列表，每次發生一個動作之
後，就會問你此時的行程樹狀態長什麼樣子。

想要看到完整解答，可以加上 `-c` 旗標，如下所示：
```sh
prompt> ./fork_zh.py -s 4 -c

                           行程樹（Process Tree）：
                               a

動作： a fork 出 b
                               a
                               └── b
動作： a fork 出 c
                               a
                               ├── b
                               └── c
動作： b fork 出 d
                               a
                               ├── b
                               │   └── d
                               └── c
動作： d 結束執行
                               a
                               ├── b
                               └── c
動作： a fork 出 e
                               a
                               ├── b
                               ├── c
                               └── e
prompt>
```

如你所見，現在每個動作之後（由左至右）都會顯示出對應變化後的行程
樹。在第一個動作「a fork 出 b」之後，你會看到一棵很簡單的樹，`a` 是
`b` 的父行程。再經過幾次 fork 之後，`d` 呼叫了 `exit`，於是這棵樹又
縮小了。最後 `e` 被建立出來，最終狀態就是 `a` 同時是 `b`、`c`、`e`
（彼此互為「兄弟」）的父行程。

在簡化模式下，你也可以只用 `-F` 旗標，練習自己動手畫出最終的行程樹：

```sh
prompt> ./fork_zh.py -s 4 -F

                           行程樹（Process Tree）：
                               a

動作： a fork 出 b
動作： a fork 出 c
動作： b fork 出 d
動作： d 結束執行
動作： a fork 出 e

                        最終行程樹？

```

同樣地，你可以再加上 `-c` 旗標來算出答案，看看自己畫得對不對（這裡
應該會對，因為題目其實是一樣的！）

# 其他選項

`fork` 模擬器還有許多其他選項。

你可以用 `-t` 旗標把問題反過來問：這時候會顯示行程樹的狀態，換成讓
你猜是哪個動作造成了這個結果。

你可以使用不同的隨機種子（`-s` 旗標），或是完全不指定，讓程式每次
隨機產生不同的序列。

你可以用 `-f` 旗標調整動作中「fork（而非 exit）」所佔的比例。

你可以用 `-A` 旗標指定確切的 fork 與 exit 序列。舉例來說，若要讓 `a`
fork 出 `b`，接著 `b` fork 出 `c`，然後 `c` 結束執行，最後 `a` 再 fork
出 `d`，只要輸入（這裡也順便加上 `-c` 直接算出答案）：

```sh
prompt> ./fork_zh.py -A a+b,b+c,c-,a+d -c

                           行程樹（Process Tree）：
                               a

動作： a fork 出 b
                               a
                               └── b
動作： b fork 出 c
                               a
                               └── b
                                   └── c
動作： c 結束執行
                               a
                               └── b
動作： a fork 出 d
                               a
                               ├── b
                               └── d
```

你可以用 `-F` 旗標，只顯示最終的輸出結果（然後試著自己推算出中間
每一步的過程）。

最後，你也可以用 `-P` 旗標，改變行程樹印列的風格。
